# Gras-Fond

Jeu de sous-marin dans l'univers de Porkonia. On pilote **La Truffe**, un sous-marin de poche de Port-Cochon, en vue à la première personne, et on peut se lever du fauteuil pour marcher dedans.

## Lancer

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # version à déployer dans dist/
```

Sur Vercel : importer le dépôt, framework « Vite », rien d'autre à régler.

## Commandes

| | Ordinateur | Téléphone (en paysage) |
|---|---|---|
| Marcher | Z Q S D (W A S D en QWERTY), souris pour regarder | joystick à gauche, glisser pour regarder |
| S'asseoir / se lever | E | bouton d'action |
| Gaz | Z / S | manette à droite |
| Cap / assiette | Q / D, flèches haut et bas | joystick |
| Ballasts | Espace chasser, Maj remplir | boutons Chasser / Remplir |
| Phares | L | bouton Phares |

## Feuille de route

1. **Prototype (en cours)** : marcher dans le sous-marin, s'asseoir, piloter, une zone de mer.
2. Récupération avec un bras articulé, Port-Cochon, vente et améliorations.
3. La guerre : sous-marins ennemis, chasse au sonar, torpilles rechargées à la main, fuites à colmater à pied.
